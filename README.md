# GitShelf Repo Planner

1. Загрузи все файлы из этой папки в корень своего GitHub-репозитория.
2. На GitHub открой Settings → Pages.
3. Выбери Deploy from a branch, ветку main и папку /(root), затем Save.
4. Открой опубликованную GitHub Pages ссылку.

Функция получает метаданные и дерево файлов публичного репозитория через GitHub REST API и формирует эвристический черновик учебного плана.

Ограничения: это не ИИ-анализ кода; README не разбирается автоматически; API имеет лимиты; большие деревья могут быть сокращены; планы сохраняются только в браузере. Не помещай секретные API-ключи во frontend.
